# 物流夜班點貨 PWA 0.047

## 0.047 主要變更
- 「提前載走」新增獨立的「00前已載走」專區，預設常用站為 `NS6`、`TS3`、`HT1`、`YT1`、`ET3`。
- 00前已載走預設為籠，可用「非預設」讓下一筆改為板；支援臨時新增其他站所與完成／修改狀態。
- 中班數量頁已完全移除舊「00前轉出總數」。
- 統計核對的中＋夜總量仍把00前已載走的籠／板加回，因此最終籠數不會少算。
- 00前已載走不會加入站所現場應有數，也不會污染03:00／05:00快速回報。
- Schema 升至15；舊版00前總籠數會安全保留為「舊版未分站」。
