# 物流夜班點貨 PWA 0.044

本版以 **0.043（實機測試 OK）** 為唯一開發基底，資料結構維持 Schema 14。

## 0.044 主要變更

中班數量盤點新增快速篩選並壓縮上方操作區：

- 系列分類：`全部 / N系列 / T系列 / C系列 / S系列 / E系列`。
- `只顯示數量0`：只顯示中班籠＋板合計為 0 的站所，並顯示目前分類範圍內的站數。
- 0數量篩選啟用時，輸入成非0並儲存後，該站自動從清單移除。
- `複製站所 / 非預設` 改成左右同排短按鈕。
- `系列分類 / 只顯示數量0` 另成左右同排，降低手機頁首高度。

## 保留 0.043／0.042 功能

- 夜班 `7 / 8 / 9 / 10 / 11 / 12` 目前滑道低亮度提示。
- 夜班 `修正數量 / 非預設` 同排左右雙按鈕。
- 夜班滑道定位列 sticky 固定，定位不隱藏任何站所。
- 定位後滑道標題不會被固定列遮住。

## 非退版

- 0.033 快速回報複製格式維持原樣。
- App 畫面站名維持小寫 t 顯示規則。
- 過境貨、回倉、提前載走、二次分理、現場盤點、統計與備份功能維持。
- 站所、第 7～12 滑道排序與預設載具均不變。

## 版本資產

- `styles-0.044.css`
- `logic-0.044.js`
- `app-0.044.js`
- `manifest-0.044.json`
- `service-worker-0.044.js`

App 啟動時會核對 App 與 Logic 版本，避免新版畫面搭配舊版邏輯。
