# 物流夜班點貨 PWA 0.064

## 0.064 主要變更

- 回倉紀錄新增「＋特殊站所」，可在當班臨時新增例如 `CS3` 的偶發回倉來源。
- 特殊站所只存在目前班次，不會加入永久固定回倉來源清單。
- 新增後會同步出現在：
  - 00後回倉站所卡
  - 00前回倉輸入清單
  - 30分鐘時段紀錄／歷史時段修正
  - 回倉複製文字上半部（有00後數量才顯示）
  - 「回倉總數含00前」下半部（當班特殊站所即使0也保留）
  - `00後合計` 與 `今日合計`
- 特殊站所可刪除；但只要00前或任何00後時段仍有籠／板數量，就會禁止刪除並跳出警示。
- 固定回倉站所沒有刪除入口，也不能透過「＋特殊站所」重複新增。
- 特殊站所代碼輸入會自動去空白並轉大寫，例如 ` cs3 ` → `CS3`。
- Schema：18。

## 資料與升級

- 0.064 從 0.063 的 Schema 17 升級至 Schema 18。
- 新增的只有班次層級 `returnCustomSources` 名單；回倉數量仍共用原本：
  - `preMidnightReturns`：00前回倉
  - `returnEvents`：00後30分鐘回倉
- 不建立第二份特殊站所數量，避免同一批回倉資料重複或不同步。
- 舊資料若已存在非固定的00後回倉來源，升級時會自動納入當班特殊站所名單。
