# 物流夜班點貨 PWA 0.065

## 0.065（10/15）主要變更

- 回倉紀錄新增固定站所 `DC10`、`CS3`。
  - 一般回倉站所卡新增於固定清單尾端。
  - 00前回倉與複製文字固定順序採 `... DC9 → DC10 → DC11 ... DC7 → CS3 → CS4`。
  - 若舊班次曾把 `CS3`／`DC10` 當特殊回倉站所，升級後會自動視為固定站所，不重複出現。
- `TS3` 預設載具改成籠車。
- 夜班產出取消「復原上一筆」UI與功能入口；事件仍可到「事件紀錄」檢視／修正。
- 滑道：`Nt24` 改到第9滑道並置於 `Nt19` 後；`Nt20` 改到第10滑道並置於 `Ct6` 後。
- 夜班上方快捷列改為三等寬：`修正數量｜非預設｜事件紀錄`，按鍵略增高以提升觸控性。
