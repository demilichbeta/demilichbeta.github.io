# 物流夜班點貨 PWA 0.067

## 0.067 主要變更

- 站所調整頁新增「恢復初始配置」。
- 初始配置直接取自 App 內建滑道基準（`CHUTES`）。
- 按下恢復後只會先載入初始配置到編輯畫面；仍需按「完成」才正式保存。
- 若誤按恢復，可按「取消」離開，原本已保存的現場配置不會被改動。
- 不提供「恢復上一次配置」；只有「恢復初始配置」。
- 既有長按拖曳、跨滑道、插入排序、全域持久化邏輯維持不變。

## 資料

- 班次 Schema：18。
- 滑道配置仍保存於 App 全域狀態，不屬於任何班次事件。
- 恢復初始配置不會修改任何盤點、回報或歷史數量。
