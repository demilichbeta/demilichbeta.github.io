# 物流夜班點貨 PWA 0.049

## 0.049 主要變更
- 二次分理改為「待處理固定顯示＋滑道臨時選站」。
- 預設不顯示所有0數量站所；上方用「全部／7／8／9／10／11／12」選擇要暫時展開的滑道。
- 0數量站所用精簡選站卡顯示；按＋1後才進入待處理區並固定顯示。
- 待處理歸0或轉完成後恢復隱藏；下方已轉完成紀錄不變。
- 滑道按鈕會顯示各滑道目前待處理站數，方便收合時掌握工作狀態。
- 本版以0.047為基底，未採用0.048的負數截斷修正；現場盤點仍保留原始負數異常訊號。
- Schema 維持15，二次分理底層事件與轉完成計算不變。

## 保留既有功能
- 0.047：「00前已載走」獨立資料區；中班移除00前轉出；最終籠／板總數仍加回00前已載走。
- 0.046：05:00複製文字排除 `NS6`、`TS1`、`TS3`；`NS15`／`Nt20` 滑道調整；新增 `Nt24`。
- 0.045：二次分理上方操作精簡與轉完成邏輯。
- 0.044：中班系列分類與「只顯示數量0」。
- 0.043：夜班第 7～12 滑道目前位置微亮。
- 0.042：夜班 sticky 快速定位與雙按鈕。
- 0.033：快速回報全形固定欄寬複製格式。
