# 物流夜班點貨 PWA 0.041

## 正式修正內容

本版以0.039為基底，保留過境貨複製、回倉合計、小寫t顯示、載具辨識及夜班點擊回饋；只把03:00／05:00快速回報的複製函式，從0.033原始碼逐字恢復。

複製格式：

```text
站所　中班　夜班　過境
ＮＳ２　２籠　１籠
ＮＴ１１　　　１板
ＴＴ２　　　　１籠
ＹＴ１　０
```

## 防止版本混用

核心資產改用實體版本檔名：

- `styles-0.041.css`
- `logic-0.041.js`
- `app-0.041.js`
- `manifest-0.041.json`
- `service-worker-0.041.js`

App啟動時會核對App與Logic版本；若不一致，直接顯示錯誤，不再讓新版畫面搭配舊版邏輯運作。

資料結構仍為第14版，0.039與更早資料可直接沿用。
