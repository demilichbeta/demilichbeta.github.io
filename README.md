# 物流夜班點貨 PWA 0.073

## 0.073 主要變更

### 回倉紀錄納入事件紀錄

- 00前回倉的增減會留下事件紀錄。
- 00後目前時段的 +1 / -1 會留下事件紀錄。
- 歷史30分鐘時段的回倉修正也會留下事件紀錄。
- 事件紀錄可用「回倉」類別與回倉來源篩選。
- 回倉事件在事件頁僅供檢視；需要修正時仍回「回倉紀錄」頁，避免兩個編輯入口互相衝突。
- 舊版既有回倉資料升級後會補成可讀的回倉事件。

## 資料結構

- 回倉正式數量仍使用既有 `returnEvents` / `preMidnightReturns`。
- 新增 `returnAuditEvents` 只保存操作歷史，不參與任何回倉加總。
- Shift Schema：19。

## 既有功能保留

- 11/07 夜班滑道初始配置與站所調整。
- T／Tt 綠色、C／Ct 橘色站所色標。
- 00前回倉、00後整點複製格式、回倉總數含00前。
- 特殊回倉站所、特殊盤點、二次分理、快速回報等既有流程。
