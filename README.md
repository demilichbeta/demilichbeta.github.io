# 物流夜班點貨 PWA 0.042

本版以 **0.041** 為唯一開發基底，資料結構維持 Schema 14。

## 0.042 主要變更

夜班頁上方操作改為較短的雙按鈕：

- `修正數量`
- `非預設`（啟用後顯示 `非預設：開`）

兩者同排左右各半。下方新增 `7 / 8 / 9 / 10 / 11 / 12` 滑道快速定位列；按下後只捲動到對應滑道，不會隱藏任何內容。定位列在往下滑時會固定於頂部。

## 保留功能

- 0.033 快速回報複製格式維持原樣。
- App 畫面站名維持小寫 t 顯示規則。
- 過境貨、回倉、提前載走、二次分理、現場盤點、統計與備份功能維持。
- 站所與第 7～12 滑道排序不變。

## 版本資產

- `styles-0.042.css`
- `logic-0.042.js`
- `app-0.042.js`
- `manifest-0.042.json`
- `service-worker-0.042.js`

App 啟動時會核對 App 與 Logic 版本，避免新版畫面搭配舊版邏輯。
