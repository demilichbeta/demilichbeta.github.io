# 物流夜班點貨 PWA 0.043

本版以 **0.042** 為唯一開發基底，資料結構維持 Schema 14。

## 0.043 主要變更

夜班頁的 `7 / 8 / 9 / 10 / 11 / 12` 滑道快速定位列新增「目前區塊」提示：

- 畫面目前位於哪一個滑道，對應數字按鈕會自動微亮。
- 微亮採低飽和藍灰色，只提高背景、邊框與文字辨識度，不使用突兀高亮色。
- 按定位按鈕時會先立即顯示選取狀態，平滑捲動後再依實際所在滑道自動更新。
- 一般夜班＋1模式與「修正數量」模式都支援。

## 保留 0.042 功能

- `修正數量`／`非預設` 同排左右雙按鈕。
- `7 / 8 / 9 / 10 / 11 / 12` 只做快速定位，不隱藏站所。
- 定位列往下滑時固定於頂部。
- 定位後滑道標題不會被固定列遮住。

## 非退版

- 0.033 快速回報複製格式維持原樣。
- App 畫面站名維持小寫 t 顯示規則。
- 過境貨、回倉、提前載走、二次分理、現場盤點、統計與備份功能維持。
- 站所、第 7～12 滑道排序與預設載具均不變。

## 版本資產

- `styles-0.043.css`
- `logic-0.043.js`
- `app-0.043.js`
- `manifest-0.043.json`
- `service-worker-0.043.js`

App 啟動時會核對 App 與 Logic 版本，避免新版畫面搭配舊版邏輯。
