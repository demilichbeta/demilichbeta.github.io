# 物流夜班點貨 PWA 0.053

## 0.053 主要變更
- 特殊盤點系列分類 UI 改成與「統計核對」一致：系列選單＋只顯示異常同列。
- 「只顯示未確認」改為獨立下一列。
- 特殊盤點載具頁籤只在預設載具旁顯示小「預」標記，不再顯示「非預設」文字。
- 籠／板任一邊有異常，載具頁籤直接顯示差異值；整張站所卡也會呈現異常邊線。
- 若只有另一個載具有異常且尚未手動選擇，會自動開啟異常載具，降低漏看非預設載具異常的機率。
- 特殊盤點色塊再收斂到既有深色面板；資料結構與確認邏輯不變。

## 二次分理資料規則
- `online`：待處理。會加入現場應有，但不進快速回報。
- `secondary`：已轉完成。轉完成時由 `online` 搬入，因此應有總數不重複增加。
- `actual`：現場實盤。轉完成時同步＋同站同載具的完成數。
- 單站與全部轉完成均使用同一套規則。

## 特殊盤點
- 特殊盤點仍是高權限入口，不建立第二份中班／夜班／過境／現場數量。
- 輸入先留在本頁草稿；按「確認此站」才以差額事件寫回正式 `events`。
- 一般提前載走、00前已載走、二次分理不會被特殊盤點重設。
- 二分待轉與已完成都會反映在特殊盤點的現場應有預覽。

## 資料結構
- Schema：16（0.053不升Schema）。
- `events` 仍是正式數量唯一來源。
- `specialInventory` 只保存確認時間與資料簽章。
- 0.051資料可直接使用，不需要額外遷移。

## 保留既有功能
- 0.051：特殊盤點共用正式資料與確認簽章。
- 0.050：現場盤點中／夜／過／總 2×2來源資訊。
- 0.049：二次分理待處理固定顯示＋滑道臨時選站。
- 0.047：00前已載走獨立資料區；最終籠／板總量仍加回00前已載走。
- 0.046：05:00複製排除 `NS6`、`TS1`、`TS3`；滑道調整與 `Nt24`。
- 0.033：快速回報全形固定欄寬格式。
- 0.048的現場應有負數截斷仍不採用。
