# 物流夜班點貨 PWA 0.045

## 0.045 主要變更
- 二次分理移除「全部 +1」。
- 「全部轉完成」與「非預設」合併成同一排。
- 移除重複的大型說明卡，改為薄型操作提示。
- 站所卡降低框線與背景強度，「無待處理」改為低對比狀態感。
- `-1／數量／+1` 的既有操作位置與計數邏輯維持不變。

## 保留 0.043／0.042 功能

- 夜班 `7 / 8 / 9 / 10 / 11 / 12` 目前滑道低亮度提示。
- 夜班 `修正數量 / 非預設` 同排左右雙按鈕。
- 夜班滑道定位列 sticky 固定，定位不隱藏任何站所。
- 定位後滑道標題不會被固定列遮住。

## 非退版

- 0.033 快速回報複製格式維持原樣。
- App 畫面站名維持小寫 t 顯示規則。
- 過境貨、回倉、提前載走、二次分理、現場盤點、統計與備份功能維持。
- 站所、第 7～12 滑道排序與預設載具均不變。
