# 物流夜班點貨 PWA 0.051

## 0.051 主要變更：特殊盤點
- 新增「其他功能 → 特殊盤點」，給中途沒時間正常盤點、最後收線才一次確認的情況。
- 特殊盤點直接讀取並修正既有中班／夜班／過境／現場資料，不建立第二份數量。
- 數字輸入先停留在本頁草稿；按「確認此站」後才以差額事件正式寫回。
- 每站支援預設與非預設載具，兩種載具的中班／夜班／過境／現場都可直接輸入。
- 畫面同時顯示來源、一般提前載走、應有與差異；已轉完成二次分理會照原統計規則包含在來源中。
- 一般提前載走、00前已載走、二次分理都不會被特殊盤點重設。
- 特殊盤點確認後，如果正常流程再改到該站的來源、載走、二次分理或現場數字，確認狀態會自動失效。
- 新增 N／T／C／S／E 分類、「未確認」及「只顯示有差異」篩選。

## 資料結構
- Schema：16。
- `events` 仍是中班／夜班／過境／一般提前載走／二次分理／現場數量的唯一正式來源。
- `specialInventory` 只保存每站確認時間與資料簽章，不保存特殊盤點數量。
- 0.050／Schema 15舊資料可直接升級。

## 保留既有功能
- 0.050：現場盤點中／夜／過／總 2×2來源資訊。
- 0.049：二次分理待處理固定顯示＋滑道臨時選站。
- 0.047：00前已載走獨立資料區；最終籠／板總量仍加回00前已載走。
- 0.046：05:00複製文字排除 `NS6`、`TS1`、`TS3`；`NS15`／`Nt20` 滑道調整；新增 `Nt24`。
- 0.033：快速回報全形固定欄寬複製格式。
- 0.048 的現場應有數負數截斷仍不採用。
